# danielbravo.cl

Sitio web de Daniel Bravo Vivallo, hecho con [Quarto](https://quarto.org) y publicado con GitHub Pages.

- Cada página es un archivo `.qmd` (Markdown con fórmulas en LaTeX).
- `_quarto.yml` define el título, el menú y el tema.
- `brand.scss` traduce el design system (colores, tipografía, espaciado) al tema del sitio.
- `images/` guarda el logo y las imágenes.

Cada cambio que se sube a la rama `main` vuelve a publicar el sitio automáticamente.
